# 🚀 Featured Projects

## 🛒 Ecommerce Data Pipeline

**PySpark • Python • PyTest • Parquet • Data Quality**

A batch data engineering pipeline for processing ecommerce data across **customers, orders, order items and returns**.

The project focuses on building a reliable transformation workflow rather than simply producing an output dataset.

### What it demonstrates

- Data ingestion and transformation
- Duplicate removal and data cleaning
- Null-key handling and validation
- Data enrichment through joins
- Data quality gates
- Unit testing with PyTest
- Partitioned Parquet output
- Analytical transformations and customer ranking
- Spark optimization using broadcast joins
- Logging and pipeline metrics

**Engineering focus:** reliability, testability, data quality and understanding how Spark transformations behave in a real pipeline.

👉 **[View Ecommerce Data Pipeline](https://github.com/Nick-Kipkoech100/Ecommerce_Data_Pipeline)**

### What it demonstrates

- Fact and dimension tables
- SQL transformations
- Analytical data marts

- Salary and job-market analysis
- Structuring raw data for downstream analytics
